# Gerador de Senhas

Projeto de um gerador de senhas desenvolvido com HTML, CSS e JavaScript.

## 🔗 Acesse o projeto

https://ginaaguiar.github.io/gerador-de-senhas/

## ✨ Funcionalidades

- Geração de senhas personalizadas
- Opção para nomear cada senha
- Escolha da quantidade de caracteres
- Opções de letras minúsculas, maiúsculas, números e caracteres especiais
- Barra de força da senha
- Copiar senha gerada
- Histórico de senhas usando LocalStorage
- Seleção e exclusão de senhas salvas
- Interface responsiva
- Visual com efeito glassmorphism

## 🛠 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Font Awesome
- Google Fonts
